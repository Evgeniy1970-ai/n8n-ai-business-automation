# 🤖 AI Business Automation Suite (n8n + OpenAI)

This repository contains ready-to-use **AI-driven automation workflows** designed to streamline routine business operations, built with **n8n** and powered by **OpenAI**.

## 🚀 Featured Agents

### 1. 📩 AI Email Business Assistant (`email_assistant.json`)
*   **Function**: Automated analysis and triaging of incoming emails.
*   **Outcome**: The AI identifies the core intent, assigns an importance level, and provides actionable advice for the manager. 
*   **Integrations**: Syncs data to **Airtable** for tracking and sends instant summaries to **Telegram**.

### 2. 📈 Strategic Competitor Price Monitor (`competitor_monitor.json`)
*   **Function**: Automated daily web scraping of competitor price lists.
*   **Outcome**: AI parses raw website data (kruszywo, sand, etc.) into structured formats, updating a central **Airtable** database on a schedule.
*   **Benefit**: Enables data-driven pricing strategies without manual market research.

## 🛠️ Tech Stack
*   **Automation Platform**: n8n
*   **Artificial Intelligence**: OpenAI (GPT-4o)
*   **Databases**: Airtable
*   **Notifications**: Telegram Bot API
